# 单排钢珠几何标定：逐步说明

对应代码：`single_row_workflow.py`；直接运行示例：`single_row_example.py`。

## 总流程

```text
RAW -> 单帧圆形目标检测 -> 跨帧永久编号 -> 每球轨迹
    -> 每条轨迹拟合椭圆 -> 椭圆中心连线求面内角
    -> 椭圆系数求主点与SDD -> 已知球间距恢复SOD和三维点
    -> 可选联合重投影精修 -> 输出报告
```

## 1. 模体与输入

钢珠沿一条直线等间距排列，邻接距离为 `d`。第 `k` 颗钢珠为

\[
X_k=X_0+k d a,
\]

其中起点 `X0` 和方向 `a` 不要求事先知道，但物理编号和间距必须正确。

示例配置集中写在Python文件顶部：

```python
CONFIG = SingleRowConfig(
    raw_path=Path(r"...raw"),
    output_directory=Path("out/cbct_calibration/single_row"),
    views=359,
    bead_count=20,
    spacing_mm=10.0,
    pixel_size_mm=(0.417, 0.417),
)
report = calibrate_single_row(CONFIG)
```

## 2. 预处理：圆形目标与亚像素质心

每帧依次执行阈值分割、8邻域连通域、半径筛选、圆度筛选、边界检查和强度加权质心：

\[
q=\frac{\sum_{p\in\Omega}(I_p-T)p}{\sum_{p\in\Omega}(I_p-T)}.
\]

边界接触或形状不合格的候选不能进入跟踪。粘连目标需要专门分割，不能把一个连通域直接当作两个球。

## 3. 跨帧编号

首帧建立轨迹编号；后续帧使用上一帧位置与距离门限匹配。某颗球一旦检测失败、越界或移动超过门限，就永久停用，不能在后续帧重新启用，以避免编号跳到另一颗球。

输出 `tracks_px` 的形状为 `(帧数, 保留钢珠数, 2)`，并保存原始 `kept_bead_ids`。距离矩阵必须按原始编号切片，不能把剩余列重新编号。

## 4. 每颗钢珠独立拟合椭圆

第 `k` 颗钢珠的多帧坐标为 `qik=(uik,vik)`，拟合：

\[
(q-c_k)^TQ_k(q-c_k)=1.
\]

得到椭圆中心 `ck`、二次型 `Qk`、轴比和条件数。行跨度过小、轨迹近似直线或条件数过差的钢珠被排除。这里不使用严格的180度径向点对。

## 5. 探测器面内旋转角

对所有有效椭圆中心拟合主方向。中心连线相对探测器V方向的角度给出面内旋转 `eta`。第一轮以图像中心旋转，随后可以用已估计主点迭代更新旋转中心。

## 6. 主点和SDD

将中心和二次型旋转到杆轴对齐坐标后，由不同椭圆间的系数差构造线性方程，求 `v0` 和像素单位的 `D²`：

\[
SDD=D\sqrt{p_up_v}.
\]

`u0`由中心线位置得到。几何像素偏移可写为

\[
offsetU=(u_c-u_0)p_u,\qquad offsetV=(v_c-v_0)p_v.
\]

具体符号必须服从重建器的U/V轴定义。

## 7. SOD与钢珠三维坐标

由每条轨迹恢复相位和归一化三维位置。已知距离 `dij` 与归一化距离 `rij` 给出尺度：

\[
SOD=\frac{\sum r_{ij}d_{ij}}{\sum r_{ij}^2}.
\]

短间距对质心误差更敏感，可以通过 `min_pair_index_gap` 排除过近点对。

## 8. 可选联合精修

精修共同优化几何和钢珠位置，最小化重投影误差并加入已知距离约束。只有在编号、质心和椭圆拟合均通过检查后才应启用。

## 9. 输出与检查

```text
tracks.npz        二维轨迹、角度、原始钢珠编号
reprojection.npz  预测轨迹和像素残差
calibration.json  参数、筛选记录、条件数和误差
```

建议检查：轨迹与椭圆叠加、椭圆中心线、逐帧残差、逐球RMSE、永久停用原因、SDD/SOD和主点的物理范围。

## 10. 当前限制

- 视角不必恰好360度，但角度必须真实、单调且不重复。
- 所有送入椭圆拟合的轨迹当前要求完整；不完整钢珠按整条轨迹排除。
- 粘连分割仍应独立增强，不能通过删除大量帧规避。
- 机械源偏移和探测器偏移的独立解释需要额外物理约束。
