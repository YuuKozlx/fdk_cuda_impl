# CBCT 几何校正

本目录是当前 CBCT 几何校正的统一入口。代码按模体业务链组织，公共数学只处理坐标、刚体变换、DLT、射线和几何拟合，不把不同模体的追踪规则强行合并。

完整文档只保留三份：

1. 本文：当前支持什么、如何选择方法、输出能否用于重建；
2. [`docs/CALIBRATION_METHODS.zh-CN.md`](docs/CALIBRATION_METHODS.zh-CN.md)：从 RAW、追踪、编号到几何参数的完整算法和公式；
3. [`docs/RECONSTRUCTION_AND_IMPLEMENTATION.zh-CN.md`](docs/RECONSTRUCTION_AND_IMPLEMENTATION.zh-CN.md)：从 DLT/联合参数到 FP、BP、迭代重建、FDK 及 Python/C++ 接口。

## 1. 总体流程

```text
平板投影 RAW
    ↓
模体专用目标检测、亚像素质心和跨帧追踪
    ↓
二维观测与已知三维模体点编号对应
    ↓
┌──────────────────────────────┐
│ 单排钢珠：多帧轨迹椭圆解析 │
│ 空间模体：逐帧 DLT/PIC      │
└──────────────────────────────┘
    ↓
每帧投影矩阵、源轨迹、PIC 量或简化圆轨道参数
    ↓
┌──────────────────────────────┐
│ 路线 A：逐帧 DLT 直接重建   │
│ 路线 B：联合拟合等效七参数  │
└──────────────────────────────┘
    ↓
SIRT/SART/OS-SART 或圆轨道 FDK
```

## 2. 当前支持的业务链

| 方法 | 模体 | RAW 追踪 | 编号 | 每帧 DLT | PIC | 源圆 | 全局联合拟合 | 推荐用途 |
|---|---|---:|---:|---:|---:|---:|---:|---|
| 单排钢珠 | 已知等间距直线钢珠 | 是 | 轨迹顺序 | 否 | 否 | 否 | 简化五参数 | 固定圆轨道 FDK |
| 可编号双环 | 大小环、异相位、外部标记 | 是 | 候选搜索与全局闭合 | 是 | 否 | 是 | 七参数 | DLT 重建或等效 FDK |
| 可编号螺旋 | 已知螺旋、外部标记 | Python | 螺旋顺序与全局闭合 | 是 | 否 | 是 | 七参数 | DLT 重建或等效 FDK |
| Cho | 同步双环，通常每环 12 球 | Python | 标记、环序与手性搜索 | 是 | Cho 解析链 | 是 | 七参数 | 论文量分析、DLT 重建或等效 FDK |
| Yang | 同步双环，每环 6 或 12 球 | Python | E/F 环和标记球 | 是 | Yang 解析链 | 是 | 七参数 | 逐帧姿态分析、DLT 重建或等效 FDK |

空间模体还有一个与具体 tracker 无关的入口：如果调用者已经提供同一坐标系中的有序三维点、有序二维点和逐点有效掩码，就可以直接执行逐帧 DLT、源圆和联合拟合。每帧至少需要 6 个有效、非退化的空间点。

## 3. 五种方法分别得到什么

### 3.1 单排钢珠

单排链在固定圆轨道、忽略面外倾斜的简化模型下估计：

```text
SOD
SDD
主点 u0、v0
探测器面内转角 eta
各有效钢珠的三维位置和相位
```

它不恢复完整的 `tilt_u/tilt_v/tilt_n`，也不能唯一分解源偏移与探测器偏移。

### 3.2 可编号双环和螺旋模体

两条链都先求每帧投影矩阵：

\[
q_{ij}\sim P_iX_j,
\]

然后输出：

```text
每帧 P_i 和重投影误差
每帧源点 C_i
源轨迹圆心、法向、半径和残差
模体坐标系到扫描仪规范坐标系的刚体变换初值
固定源规范下的 SID/SDD/offset_u/offset_v/tilt_u/tilt_v/tilt_n
```

双环依赖环半径、环间距、相位和标记关系；螺旋利用轴向顺序降低双环的周期对称性。两者的逐帧 DLT 都可以直接驱动迭代重建。

### 3.3 Cho

Cho 链保留论文的椭圆几何，同时用 DLT 给出完整逐帧射线。主要输出：

```text
两个环的投影椭圆
收敛点和特征线
论文定义的 eta
每帧 P_i、源点、主点、SDD 和探测器 U/V/N
源圆统计
固定源规范七参数
```

单帧 `eta` 是相对于模体参考系的量。模体歪斜时不能直接把它写成机器的 `tilt_n`。

### 3.4 Yang

Yang 链按论文步骤输出：

```text
O：模体中心的透视投影
eta/yaw
两个投影椭圆
theta/roll
phi/pitch
虚拟探测器坐标中的 S 和 W
SDD、主点、源到模体中心/轴线距离
gantry angle
每帧 P_i 和统一 fdk-test 坐标下的重建几何
固定源规范七参数
```

`O` 不是主点；`|SW|` 也不必等于机械 SID。Yang 的论文坐标只存在于内部解析步骤，公开重建结果统一转换到本项目的右手三维坐标系。

## 4. 三类输出不能混用

### 4.1 每帧投影矩阵

`P_i` 定义模体/重建空间点到探测器像素的投影：

\[
\begin{bmatrix}u\\v\\1\end{bmatrix}
\sim P_i
\begin{bmatrix}x\\y\\z\\1\end{bmatrix}.
\]

它已经包含该帧的源位置、探测器姿态、模体参考系和主点效应。只要重建体与标定三维点使用同一坐标系，`P_i` 就可以直接用于射线驱动的正投和反投。

### 4.2 PIC 逐帧量

Cho/Yang 的 `O、S、W、eta、roll、pitch、gantry angle` 用于解释每帧的几何构造和检查机械波动。部分量位于论文虚拟探测器或模体坐标系，必须经过坐标适配后才能进入重建。

### 4.3 全局等效七参数

为兼容圆轨道 FDK，当前联合拟合固定：

```text
source_offset_x/y/z = 0
offset_n = 0
```

并估计：

```text
SID、SDD、offset_u、offset_v、tilt_u、tilt_v、tilt_n
```

模体的三维旋转和平移同时作为 6 个 nuisance 参数优化。这组结果在选定规范下重现射线，适合重建，但不应自动解释为唯一机械安装误差。

## 5. 如何选择路线

### 5.1 只需要固定圆轨道的简化校正

使用单排钢珠。它的模体容易制作，公式清晰，但模型自由度有限。

### 5.2 希望尽量少依赖理想机械模型

使用可编号双环或螺旋模体，获得逐帧 `P_i`，直接走 DLT 迭代重建。这条路线不要求把源偏移和探测器偏移唯一拆开。

### 5.3 必须使用现有 FDK 接口

先用空间模体得到逐帧 DLT 和源圆，再在明确固定源规范后联合拟合七参数，最后生成标准圆轨道几何。

### 5.4 需要分析每帧探测器姿态

使用 Cho 或 Yang PIC，同时保留 DLT 结果作为重投影和射线闭合检查。PIC 量和机械量之间必须经过统一坐标系与多帧约束，不能只看某一帧的角度。

## 6. 追踪和粘连的统一语义

Cho、Yang、可编号双环和螺旋链使用：

```text
observed：目标仍属于当前前景
merged：多个目标共享同一个连通域
usable：observed && !merged
```

粘连帧中的预测坐标只用于延续编号，不作为真实测量进入 DLT、PIC 或联合残差；目标在后续帧重新分离后可以恢复使用。单排钢珠保留严格策略：检测失败、出界或运动超限后永久停用。

## 7. 坐标约定

公共图像坐标与 `fdk-test` 一致：

```text
RAW shape = [view, row, column]
u = column，向右增加
v = row，向下增加
pixel center = ((Nu - 1)/2, (Nv - 1)/2)
```

探测器始终作为三维右手坐标系处理：

```text
U × V = N
D(u,v) = detS + u*detU + v*detV
```

论文坐标、模体坐标和扫描仪坐标之间只允许使用显式刚体/投影变换，不允许只在二维结果上临时翻转一个符号。

## 8. Python 与 C++ 边界

Python 当前覆盖完整业务链：

- 五类模体的专用追踪和编号；
- Cho/Yang PIC；
- 归一化 DLT、坐标适配和源圆；
- 固定源规范七参数联合拟合；
- JSON、NumPy 和诊断图输出。

独立 C++ 标定工程当前覆盖：

- 单排钢珠检测与追踪；
- 可编号双环 RAW 追踪；
- Cho/Yang/可编号模体点集工厂；
- 已编号点与逐点 `usable` 掩码；
- DLT、源圆、七参数联合拟合和 JSON 输出；
- 粘连屏蔽与后续帧恢复。

C++ 尚未完整替代 Cho/Yang PIC、Python 的全部镜像候选业务以及螺旋 RAW 专用追踪。DLT FP/BP 和迭代重建属于主库的 CUDA 模块，不属于独立标定 CMake 工程。

## 9. 当前不能声称解决的问题

- 没有机器基准时，不能唯一分解真实源偏移和探测器偏移；
- 单张普通投影不能独立给出机械 `offset_u/offset_v`；
- 模体姿态未知时，PIC 的逐帧姿态不能直接当作机器安装姿态；
- 单排钢珠不能恢复完整三轴探测器倾角；
- 通用 DLT 需要可靠的三维—二维编号，不会自动理解任意未知模体；
- DLT 的射线是唯一的，但对应的有限探测器平面和机械 SDD 不是唯一的；
- 粘连预测点不能替代真实亚像素质心。

## 10. 验收原则

一次标定不能只检查最终七个数字。至少同时检查：

```text
每帧检测数量和 usable 数量
标记、上下环、相位和手性是否正确
每帧 DLT 重投影 RMSE 与最大误差
源圆平面残差和半径波动
联合拟合 RMSE、参数边界和收敛状态
逐帧 PIC 曲线是否存在毛刺或分支跳变
重建结果是否闭合、是否出现双边缘或几何拉伸
```

测试环境、函数入口、输出字段和重建接入方法见第三份文档。
