# C-FDK 实现说明

## 定位

C-FDK（curve-filtered FDK，Li 等，2011）是针对**平板探测器、理想圆轨迹**的曲线滤波 FDK 改进。它不是柱面探测器重建器，也不是 xFDK 的扩展范围算法。当前实现入口为 `Fdk::CurveFilteredFdkPipeline`。

## 坐标和数据

输入投影按 `[view][v][u]` 排列，`u/v` 是实际平板像素坐标。算法内部在经过等中心的虚拟平面上使用 `(a,b)`，并将其重排为曲线坐标 `(t,c)`。`R=SID`，`D=SDD`，探测器物理间距为 `du,dv`。

## 处理步骤

1. **曲线重排**：对每个 `(t,c,theta)` 计算
   `q=sqrt(R^2-t^2)`、`a=tR/q`，并依据 `|c|` 所在分段求 `b`。再以 `D/R` 缩放 `(a,b)`，回到原始平板纹理采样。
2. **余弦预加权**：重排 kernel 同时乘论文 Jacobian 权重。三段分别使用 `c0` 内核、`c0..s0` 过渡式和 `s0..bm` 外侧式，代码对应 `YkCurveFilteredFdkKernels.cu`。
3. **滤波**：沿 `t` 方向逐行执行公共 FDK ramp 滤波；`dt` 是距离采样间隔，滤波核由 `[case.filter]` 选择。
4. **反投影**：对每个体素和每个视图计算 `(t,v)`，用论文式 (35) 的三段逆映射得到 `c`，从滤波纹理双线性取样并乘 `0.5*DeltaTheta` 累加。

## 分段边界

`c0`、`s0`、`bm` 是曲线重排的数学分界，不是 xFDK 的可见角或扩展范围边界。三段含义是：中心区域的第一条映射、连续过渡区域、靠近探测器边缘的外侧映射。代码在边界使用闭区间并加入浮点容差；超出 `bm` 或 `R^2-t^2<=0` 的样本填零。

## 边界和适用条件

- 只接受不重复终点的等角完整 `2pi` 圆扫描；
- 不接受源偏移、探测器 offset/tilt/skew、非水平轨迹或短扫描；
- 输入和滤波纹理采用 `cudaAddressModeBorder`，越界采样为零；视图方向单独按周期处理；
- C-FDK 不扩展 z 向覆盖范围，端部改善取决于原始探测器锥角；
- 当前实现需要整幅设备投影，不提供在线分包接口；
- 结果的绝对量纲仍需用已知均匀模体标定，不能只看相关系数。
