# 系统参数四几何重建样例

实现文件：`Yktest/example_system_reconstruction.cpp`

该样例不要求调用方填写逐视图 vector geometry，而是从宏观系统参数开始：

1. 设置规则扫描轨迹、探测器和重建体积；
2. 通过系统 geometry builder 生成逐视图几何；
3. 使用对应 FP 对同一 ASTRA modified 3-D Shepp-Logan 模体生成投影；
4. 分别执行四种几何适用的重建；
5. 保存重建体 RAW 和横断面对比 BMP。

| 系统请求 | 几何 | 重建方法 | 说明 |
| --- | --- | --- | --- |
| `SStaticFlatReconstructionRequest` | 静态平板圆扫 | Flat FDK | 使用 Shepp-Logan 滤波，Parker 为 Auto |
| `SStaticCylReconstructionRequest` | 静态柱面圆扫 | Cyl analytic FDK | 使用柱面修正 Ram-Lak |
| `SHelicalFlatReconstructionRequest` | 平板螺旋 | OSSART | 3 轮、12 子集 |
| `SHelicalCylReconstructionRequest` | 柱面螺旋 | Cyl OSSART | 3 轮、12 子集 |

这里的四条路径都使用 Shepp-Logan **模体**。只有 Flat FDK 使用
Shepp-Logan **滤波器**；当前 Cyl analytic FDK 只实现了柱面采样修正的
离散 Ram-Lak，迭代重建没有解析滤波阶段。

运行：

```powershell
.\build-helical\Yktest\Release\ykcbct_manual_tests.exe `
  example/system-reconstruction-four-geometries
```

输出目录：

```text
out/test-artifacts/system-reconstruction-four-geometries/
```

`comparison.bmp` 从左至右依次为：

```text
Shepp-Logan 真值
静态 Flat FDK
静态 Cyl analytic FDK
Heli Flat OSSART
Heli Cyl OSSART
```
